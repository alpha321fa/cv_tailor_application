# AI Usage

## Which tools I used and what for
I used Claude Code for building and planning this application and OpenRouter for accessing LLMs.

## Any incorrect or unhelpful suggestions
Not really. If any mistakes were made within the code, Claude Code would have found it and fixed it on its own.

## How I verified suggestions
I created this application step by step rather than all at once. At certain points, I asked Claude Code to review what it has done and sometimes that would cause Claude Code to find some small issues which it would then fix. I have also verified any LLM output through manual testing and inspection.

# Research

## What I needed to learn and why
I had to learn how to be able to use and access OpenRouter to gain access to free LLMs. I also had to consider how I would test the application as there are limits on how often I can call the free LLM. The parts of the application where the model was used, I tested it manually by looking at the LLM output and seeing whether the tailored CV was accurate.

## Where I looked and how I assessed the information
I was already aware of OpenRouter before I started this challenge. So I knew that I was going to have to use something like OpenRouter to access free LLMs. OpenRouter was straightforward to use so figuring out how to access the models wasn't difficult.

## Problems or approaches that didn't work
My initial approach with this challenge was to plan the application in depth and then use Claude Code to create this application. Though I found that it took too much time and too finicky trying to perfect a plan. So I decided it would be more effective to tell Claude Code the basic idea of the application and then build on top of what it produces.

## What I learned
I have learned about the effects of using free LLMs for an application, having to take things like usage limits and testing into account. I have also learnt that for smaller applications like this one, a more agile approach is more effective rather than trying to create a perfect application from the start.
